# 🚂 极简铁路调度运营游戏（Mini Rail Operations）

> **《极简铁路调度运营》**是一款极简矢量风格的铁路建造与调度模拟游戏。白天你手动切换道岔、控制列车启停与发车，把带着明确目的地的乘客准时送达；夜晚用赚来的钱铺轨建站、扩充车队，备战明天的客流高峰。游戏最大的亮点是"零自动化"的硬核调度——没有信号灯、没有自动排班，每一条进路都靠你亲手拨动道岔，在繁忙的单线铁路上玩出紧迫感十足的交通博弈。
>
> 灵感来自《Mini Metro》的极简视觉与 OD 客流系统，以及《OpenTTD》的自由轨线拼接与站台/列车长度匹配机制。纯 HTML5 Canvas 实现，零外部依赖。

---

## 🎮 游戏简介

你是一座城市铁路网的总调度员。

**白天**，列车在线路上飞驰，你要在站台之间手动切换道岔、控制发车与停靠，把源源不断涌来的乘客准时送往目的地——偶尔还要面对满载、积压和调度失误的考验。

**夜晚**，城市安静下来，你用白天运送乘客赚来的钱购买轨道、站台和车厢，规划下一张更庞大的路网，为明天的客流高峰做准备。

游戏的核心循环：

```
夜晚（结算 + 商店 + 建造）→ 白天（10分钟实时运营）→ 结算（评估运送率）→ 下一周期
```

这不是一个"放置就能自动运行"的模拟器。没有自动信号灯、没有线路自动排班——**每一条进路都靠你亲手切道岔**，每一次发车都靠你亲自下令。调度失误的代价，是滞留站台的乘客，和一路下滑的城市满意度。

---

## 💡 设计理念

> **"极简不等于简单，而是用最少的工具创造最深的调度博弈。"**

- **没有信号灯** —— 用道岔 + 限速 + 制动距离计算实现安全博弈
- **没有特急工具** —— 用跳站设置 + 侧线组合实现
- **没有线路类型** —— 画一条是单线，并行两条就是复线
- **没有自动分配** —— 全靠手动切道岔决定列车进路

玩家的每一条轨道、每一个道岔、每一列列车的配置，都在用最基础的元素表达高级策略。

## ✨ 核心特性

### 🛤 自由物理轨线

- **拖拽铺设轨道**：按住鼠标划线，系统自动生成"斜线 + 直线"的最优路径，无需一格一格拼接
- **单复线自由**：画一条是单线，并行画两条即为复线
- **自动道岔**：轨道交叉处自动生成道岔节点。仅 **45° 斜向分支** 才算有效道岔，纯十字交叉、直角 T 字路口不生成道岔
- **点击切换方向**：道岔处点击即可循环切换路径方向，黑点 + 连接短线清晰指示当前接通方向
- **方向约束**：道岔只允许 45° 变向与直行，禁止反向、直角与 135° 大转弯

### 🏭 车辆段与编组

- 开局赠送一座**车辆段**，需用轨道连接到铁路网方可使用
- 商店购买**车厢**（每节 1 格长）→ 在车辆段自由编组（1~8 节）
- 运营阶段点车辆段，随时手动发车 / 查看停放列车
- 列车按车厢**分节渲染**，转弯时逐节铰接跟随（trail 轨迹系统），模拟真实列车的蛇形过弯

### 🎛 手动调度运营

- 运营中**点击道岔**切换列车行进方向
- **启停 / 调头**按钮 + 快捷键，随时控制任意列车
- 列车到站自动停车上下客，**一站只停一次**（多个站台格也只在最前部停靠一次）
- 轨道尽头**自动调头**
- 列车带载客量显示（如 `12/40`），点击查看详细客流去向

### 🧑🤝🧑 OD 客流系统

- 每位乘客携带明确的**目标站点**
- 目的地按**客流等级加权分配**——越大的站越容易被选为目的地
- 每站每秒持续生成乘客，生成速率受满意度影响
- 每格站台提供 **50 人缓冲**，超出后扣减满意度

### 😊 满意度系统

- 初始 100%，车站积压超载时**每游戏小时扣减**满意度
- 高运送率 / 全站零积压时**结算恢复**
- 车站人数颜色编码：`<40` 黑 / `≥40` 黄 / `≥50` 红 / `≥100` 红闪警告
- 满意度 < 10% 持续 3 天 → 城市满意度崩溃，游戏结束

### 🛡 闭塞防撞系统

- **格级 cellOccupancy** 占用队列：前后车自动保持安全间距
- **对头闭塞**：两车对向互阻防重叠
- **追尾防护**：后车自动停等前车离开
- 列车尾部溢出站台会**物理阻挡正线**，长编组需要长站台

### ⛰ 地形系统

- FBM 噪声 + 河谷噪声程序化生成随机山河平原
- 站点自动随机放置于平原，避开不可建造地形
- 地图大小与站点数量可在主菜单自由调节

### 🌗 昼夜循环与经济

- 每个白天 **10 分钟**（06:00 ~ 24:00 时钟显示）
- **1x / 2x / 3x / 5x / 10x** 倍速，随时暂停
- 收入 = 运送乘客数 × ￥2，维护费 ￥30/天
- 商店支持 **[1] [5] [10]** 批量购买轨道组件 / 站台组件 / 车厢
- 破产或满意度崩溃 → 游戏结束

### 💾 存档系统

- **自动存档**（每天结算后）+ **手动保存**
- **Base64 文本导入导出**，方便跨设备迁移存档
- 未保存就关闭页面 → 浏览器弹窗警告
- 齿轮 ⚙ 设置面板，分页式管理

### 🔊 音效系统

- Web Audio API 程序化生成音效与背景音乐
- 主音量 / 音效 / 音乐独立控制，自动记忆偏好

### 通用操作

| 操作 | 键位 / 鼠标 |
|------|------------|
| 平移视角 | 中键 / 右键拖拽 |

| 操作 | 键位 | 说明 |
|------|------|------|

| 拆除 | `3` | 拖拽擦除轨道 / 站台 |

| 操作 | 键位 | 说明 |
|------|------|------|
| 启停列车 | `1` | 进入模式后点击列车 |
| 调头 | `2` | 进入模式后点击列车 |
| 切换道岔 | 左键 | 点击岔道黑点切换方向 |
| 车辆段发车 | 左键 | 点击紫色车辆段 |

## 🛠 技术栈

- **原生 HTML5 Canvas 2D** 渲染，无任何框架
- **零外部依赖**，纯前端单页应用
- 模块化架构，每个系统独立文件

### 项目结构

```
mini rail operations/
├── index.html          # 页面骨架（主菜单/顶栏/侧边栏/画布）
├── style.css           # 极简矢量风样式
├── js/
│   ├── main.js         # 入口 + 游戏循环 + 阶段切换
│   ├── gameState.js    # 全局状态 / 存档 / 坐标转换
│   ├── gridGraph.js    # 轨道图结构 + 道岔逻辑
│   ├── terrain.js      # 程序化地形生成
│   ├── station.js      # 站台 / 客流 / OD 系统
│   ├── train.js        # 列车物理 / 闭塞 / 调度
│   ├── renderer.js     # Canvas 渲染
│   ├── input.js        # 输入 / 相机 / 工具
│   ├── ui.js           # 界面面板 / 满意度 / 设置
│   ├── menuDecor.js    # 主菜单装饰动画
│   └── audio.js        # Web Audio 音效系统
├── 策划文档.md          # 完整游戏设计文档
└── 功能完成清单.md      # 开发进度对照表
```

## 🚀 本地运行

项目是纯静态页面，任意静态服务器即可运行：

```bash
# 方式一：Python
python3 -m http.server 8765
# 打开 http://localhost:8765

# 方式二：Node
npx serve

# 方式三：直接双击 index.html（部分功能需服务器环境）
```

> 推荐使用 http.server，存档与音频在 file:// 协议下可能受限。
